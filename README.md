# Anonymous-Implementation-for-AsiaCCS

Prototype Implementation for "Breaking and Fixing OQXT"

//Compile and Run

Run "Make"
For tOQXT, run ./toqxt
For OQXT, run ./oqxt

//Updating number of keywords and maximum frequency

Navigate to tools.h
Update "sizew" to change the number of keywords
Update "sized" to change the maximum frequency of any keyword
Update sizewid to (sizew times sizeid)

//Note

You need OpenSSL version 3.0.2 or more installed on your system
